# 03 · Orders

Gestión de un pedido (cabecera / detalle) con **React**, **useReducer** y **Material UI**.

## Funcionalidades

- Importe total y estado (% de líneas validadas) calculados.
- Validar / invalidar las líneas seleccionadas y editar su importe.
- Botón de enviar habilitado solo al 100%.
- Cabecera dividida en dos componentes, uno de ellos con `React.memo`.

## Instalación

```bash
npm install
```

### Desarrollo

```bash
npm start
```

Levanta el servidor de desarrollo en `http://localhost:5173`.
