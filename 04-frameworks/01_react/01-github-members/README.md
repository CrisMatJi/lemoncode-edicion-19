# 01 · GitHub members

Listado de miembros de una organización de GitHub con **React**, **React Router** y **Material UI**.

## Funcionalidades

- Login con `admin` / `test`.
- Búsqueda por organización (por defecto `lemoncode`), que se mantiene al volver del detalle.
- Paginación del listado.
- Página de Rick & Morty con búsqueda (`useDebounce`), paginación y detalle.

## Instalación

```bash
npm install
```

### Desarrollo

```bash
npm start
```

Levanta el servidor de desarrollo en `http://localhost:5173`.
