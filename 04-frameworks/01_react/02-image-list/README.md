# 02 · Image list

Listado de imágenes con carrito de la compra usando **React Router**, **Context** y **Material UI**.

## Funcionalidades

- Dos páginas (`Kitties` y `Puppies`) con imágenes seleccionables.
- Carrito fuera del router, sincronizado con las páginas a través del contexto.
- Ocultar y vaciar el carrito.
- Página de checkout.

## Instalación

```bash
npm install
```

### Desarrollo

```bash
npm start
```

Levanta el servidor de desarrollo en `http://localhost:5173`.
