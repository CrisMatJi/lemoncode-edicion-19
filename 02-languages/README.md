# Módulo 02 - Lenguajes

Ejercicios del módulo de lenguajes del [Master Frontend Lemoncode](https://github.com/Lemoncode/master-frontend-lemoncode/tree/master/02-languages).

> Los playgrounds utilizados como base son los proporcionados en el repositorio oficial del máster.

## Ejercicios

| Carpeta | Descripción | Tipo |
|---|---|---|
| `01_array-operations` | Operaciones con arrays | JS |
| `02_concat` | Concatenación y spread | JS |
| `03_clone-merge` | Clonado y merge de objetos | JS |
| `04_read-books` | Gestión de libros | TypeScript |
| `05_slot-machine` | Máquina tragaperras | TypeScript |

## Uso del playground

### Ejercicios JS (01, 02, 03)

Abre el fichero `index.html` directamente en el navegador o con la extensión **Live Server** de VS Code.

El código de cada ejercicio está en `playground.js`. Los resultados se muestran en la **consola del navegador** (`F12`).

### Ejercicios TypeScript (04, 05)

1. Instala las dependencias:

```bash
npm install
```

2. Arranca el servidor de desarrollo (compila TS en modo watch y abre el navegador):

```bash
npm start
```

El código fuente está en `src/`. Los resultados se muestran en la **consola del navegador** (`F12`).
