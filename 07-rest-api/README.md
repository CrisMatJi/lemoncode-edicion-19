# Módulo 07 - REST API

Laboratorio del módulo de REST API del [Master Frontend Lemoncode](https://github.com/Lemoncode/master-frontend-lemoncode/tree/master/06-rest-api/laboratory): consumir la [API de Rick & Morty](https://rickandmortyapi.com/documentation/#rest).

> Cada carpeta parte del boilerplate `laboratory` del repositorio oficial, cambiando las escenas, rutas y pods de hotel a `character-collection` y `character`.

## Ejercicios

| Carpeta | Descripción | API |
|---|---|---|
| `ejercicio-1` | Listado de personajes y detalle (axios) | API real |
| `ejercicio-2` | Igual que el 1 + editar y guardar `bestSentence` | Server local |
| `opcional` | Paginación, búsqueda, lugares y episodios | API real |

## Uso

Dentro de cada carpeta:

```bash
npm install
npm start
```

- Web: http://localhost:8080
- Server mock (carpeta `server`): http://localhost:3000

El `postinstall` instala también las dependencias del server.
