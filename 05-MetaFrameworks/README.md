# Módulo 05 - MetaFrameworks

Laboratorio de MetaFrameworks del [Master Frontend Lemoncode](https://github.com/Lemoncode/master-frontend-lemoncode): portal de alquiler de casas rurales con listado y detalle, hecho con dos metaframeworks.

| Carpeta | Framework | Rendering |
|---|---|---|
| `01-nextjs` | Next.js (App Router) | Listado ISR, detalle SSG + ISR |
| `02-nuxt` | Nuxt 4 | SSR con caché `swr` |

Las dos usan el [mock api-server](https://github.com/Lemoncode/master-frontend-metaframeworks-lab) del laboratorio, incluido en cada carpeta. Cada proyecto tiene su propio README con los detalles.

## Arrancar

Dentro de cada carpeta:

```bash
npm install
npm start
```
